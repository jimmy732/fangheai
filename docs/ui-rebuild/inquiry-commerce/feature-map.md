# F-Box 询盘商业化功能映射

- 前台在线客服：保存客户、语言、车型选择、官方 OEM 轮毂数据、客户定制轮毂数据、商品快照和最多 3 张效果图。
- 后台询盘详情：商品卡、销售价、车型、官方数据、客户数据、效果图、客户等级 A/B/C、消息时间线。
- 报价卡：成本价仅后台可见；客户售价、数量、运费、物流方式、生产天数、运输预估天数、备注进入客户会话。
- 支付：客户点击报价卡内的 PayPal 按钮，由独立站后端创建 PayPal Orders v2 订单并跳转批准页；返回后由后端 capture，完成后更新报价和询盘状态。
- 现有商城购物车/订单链路保持不变；报价支付是 F-Box 询盘的独立链路。
